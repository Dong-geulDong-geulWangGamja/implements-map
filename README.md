# 카카오맵 API를 사용하여 지도 구현

프로젝트를 실행시키기 위해서는 카카오맵 API와 Firebase 연결이 필요합니다

## 센서를 이용한 위험도 표시

센서를 통해 데이터 베이스에 저장한 데이터를 일정 시간마다 갱신하여
사용자에게 보여줍니다

## 실행 방법

### `npm install`

node_modules를 설치하기 위한 명령어

### `npm start`

local서버의 3000포트에서 실행하여 웹페이지 실행
[http://localhost/3000](http://localhost:3000)
을 통해 볼 수 있습니다
* 카카오맵 API에 등록한 주소와 동일해야 함
